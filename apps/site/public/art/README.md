# Original SVG art

All files are original artwork written by hand as SVG for Bhagwati Caterers (created 2026-11-27). Palette: haldi #F2B01E, kesari #E8750A, maroon #7A1F2B, leaf green #3E7B3A, peacock teal #0F7C80, cream #FFF6E3, ink #2B1B14 plus tints. No text, fonts, scripts or external references; each file is under 10 KB and has a `<title>` (use it as the starting point for alt text; translate to Marathi/Hindi). Motifs are "inspired by" Paithani and Warli traditions, not copies. Open `preview.html` to see everything.
