# Image and Graphic Credits

**Rule:** no image, graphic or font goes into the site without a row here.

## Process
1. Record the source, licence, the date you checked the licence, and the link.
2. Save a screenshot of the licence page for stock assets.
3. Flag if the image shows people, logos or brands. If it does and there is no written consent or release, do not use it.
4. Mark whether attribution is required. If yes, it also goes on the `/credits` page.
5. Never label a stock photo as "our food" or "our event".

## Status key
`own` = owner's photo, `svg` = original art made for this project, `stock` = third-party, `placeholder` = temporary, must not go live
