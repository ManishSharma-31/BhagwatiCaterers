# Admin portal UX review, round 2

Scope: apps/site/src/admin (Preact), built and served locally, screenshots in /tmp/ux2 (phone 390x800, 360 for Marathi, desktop 1280x800 and 1918x900). Every route was visited with demo data: today, leads (list, new, detail), events (calendar, new, detail), sheets, quotes (list, new, editor), payments (list, form), tasks, staff, settings, search, more, 404. No source file was edited.

Method note: phone full-page screenshots show the fixed bottom tab bar in the middle of the page. That is a screenshot artefact, not a bug. Things I could NOT verify: real-phone keyboard behaviour, date-picker format on an Indian-locale device (headless Chrome shows mm/dd/yyyy), actual paper print output (only `emulate_media print` screenshots), screen reader behaviour, the cloud-signed-in and PIN lock screens (read from code only), and the Sheets screen with dishes selected (the demo event has none).

## (a) Summary

The portal is in good shape. Layout is clean, no horizontal overflow on any route at any width, the script found no JS errors, most tap targets are 44px or more, the phone and desktop shells both work (bottom tabs below 960px, sidebar above), and the Marathi text fits at 360px. Delete has a confirm plus an undo toast, the phone, date and number inputs have the right keyboard types, and duplicate-phone and past-date warnings exist.

The weak points are about speed and focus for a non-technical owner on a phone:
1. Today pushes the owner's real work (follow-ups, events) below a large red backup banner, six tiles and a pipeline.
2. Forms are long, with many optional fields before the primary action. The Save button is not sticky on Payments, Events or Quotes.
3. A few fixed elements collide: FAB over list text, undo toast over the sticky Save bar.
4. Print output for quotes and kitchen sheets is bare (no quote date, no terms, no empty-state handling).
5. Several smaller inconsistencies (Devanagari digits next to Latin money digits, English-only strings in Marathi mode, 28px back links, 22px checkboxes).

## (c) Top 10 changes, ranked by value for the owner

1. F01: Put "due today" (follow-ups, events, tasks) first on Today; shrink the backup banner.
2. F07: Faster "record advance": event picker first, Amount autofocus, sticky Save.
3. F10: Quote editor: sticky Save and Share bar, live total at the top, Delete moved away from Accepted/Rejected.
4. F05: New lead: autofocus name, collapse secondary fields, default the follow-up to tomorrow.
5. F08: Event detail: surface Quote / Money / Kitchen sheets above the long form, move Delete far from Save.
6. F03 and F04: Stop the FAB and the undo toast covering content and the Save bar.
7. F12 and F13: Better print output (quote date, terms, event date, dishes, `@page` rule; do not offer printing an empty sheet).
8. F16: Single-line brand and no "This device" pill in the phone topbar (reclaims about 20px and removes jargon).
9. F15 and F24 and F14: Make every tap target at least 44px (back links, action buttons, scale chips).
10. F22: One numeral system in Marathi mode; plus F20 (Backup first and signposted in Settings).
