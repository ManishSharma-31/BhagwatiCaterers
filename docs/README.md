## Rules for everyone working on this repo

1. Never add an image or graphic without a row in `image-credits.md` (source, licence, date, attribution needed or not).
2. Prefer the owner's own photos. Use original SVG art made for this project, or CC0 / public-domain / permissive-licence stock, in that order.
3. Do not use brand logos, recognisable people, film or TV characters, or copied design templates.
4. No secrets (keys, passwords, tokens) in the repo.
5. Log important decisions in `decision-log.md`.
6. Update `task-board.md` when starting and finishing work.
